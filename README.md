# Bangalore Air Quality Index (AQI) Dashboard 🌍

An interactive web dashboard that explores Bangalore's air quality trends from **2014 to 2024**. The project presents air pollution information through charts, maps, statistics, heatmaps, and station-wise comparisons to make environmental data easier to understand.

## 📌 Project Overview

Air pollution is an important environmental concern in Bangalore. This dashboard helps users explore how air quality has changed over the years, compare pollution levels across different geographical zones, and identify areas with higher and lower pollution levels.

The dashboard covers:
- 100 monitoring stations
- 13,200 monthly records
- 11 years of data (2014–2024)
- 5 geographical zones

## ✨ Features

### 1. City Overview
- Average AQI statistics for Bangalore.
- Highest and lowest recorded AQI values.
- Most polluted and cleanest monitoring stations.
- AQI category distribution.

### 2. Decade-Wise Analysis
- AQI trends from 2014 to 2024.
- Year-wise pollution comparisons.
- Zone-wise AQI trends.
- Comparison of pre-lockdown, lockdown, and post-lockdown periods.

### 3. Geographical Zone Comparison
Explore air quality across five zones:
- North Bangalore
- South Bangalore
- East Bangalore
- West Bangalore
- Outskirts

### 4. Weather Analysis
Explore the relationship between air quality and weather conditions:
- Temperature
- Humidity
- Rainfall
- Wind conditions

### 5. Pollutant Analysis
Visual representation of major air pollutants:
- PM2.5
- PM10
- NO2
- SO2
- CO
- O3

### 6. AQI Heatmap
A monthly and zone-wise heatmap that helps identify seasonal pollution patterns.

### 7. Interactive Station Map
- Displays monitoring station locations.
- Uses different colours to represent AQI categories.
- Allows users to click on stations to view additional information.

### 8. Station-Wise Data
- Information about all 100 monitoring stations.
- Average, minimum, and maximum AQI values.
- Zone-wise filtering.

### 9. Pollution Risk Classification
Identifies high-risk, moderate-risk, and low-risk areas based on the dashboard's data.

## 🚀 How to Run the Project

This project uses a single HTML file and does not require a backend server.

1. Clone the repository:

   ```bash
   git clone https://github.com/mayasha13/bangalore-aqi-dashboard.git
   ```

2. Open the project folder:

   ```bash
   cd bangalore-aqi-dashboard
   ```

3. Open `index.html` in your web browser.

4. Explore the different dashboard sections.

**Note:** An internet connection is required to load external libraries, map resources, and Google Fonts.
